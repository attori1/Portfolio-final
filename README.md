# portfolio

Mon portfolio personnel, conçu comme une interface VS Code — sidebar, onglets, barre de statut.

Construit avec React + Vite.

## Pages

| Fichier | Contenu |
|---------|---------|
| `README.md` | Accueil / intro |
| `about.md` | Qui je suis |
| `now.md` | Sur quoi je travaille |
| `projects.md` | Projets sélectionnés |
| `skills.json` | Stack technique |
| `contact.sh` | Me contacter |

## Lancer en local

```bash
npm install
npm run dev
```
